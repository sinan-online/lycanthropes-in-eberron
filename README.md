# lycanthropes-in-eberron
What if werewolves of Eberron were twelve different ``tribes'', each impacted by a different moon of Eberron?

This book is inspired by [the homebrewed lunar calendar of Eberron by abexy](https://drive.google.com/file/d/1XxNb80pKTArS2SecLkFQE3nnbXTwt2j9/view) and the classical World of Darkness game, Werewolf: the Apocalypse by White Wolf.\par

The rules are intended for players to play as lycanthropes, specifically werewolves, in Eberron campaigns.
